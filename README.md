<h1 align="center">✨ CRUD - Gestão de Clientes ✨</h1>

<p align="center">Esse projeto é baseado inteiramente em Python e usa funcionalidades das bibliotecas SQLite, Tkinter e CustomTkinter
para criar uma interface que se relaciona diretamente com o banco de dados.</p>
